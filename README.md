# عقلني (Aqlni) — تعلّم ولعب بذكاء 🎒

لعبة تعليمية عربية كاملة للأطفال (5–14 سنة)، تعمل **بلا إنترنت 100٪**، مبنية على
محرّك HTML5 عربي داخل صدفة أندرويد أصلية (Kotlin + WebView).

العوالم السبعة:

| العالم | الأنشطة |
|---|---|
| 🔢 الرياضيات | اختبار تكيفي، سباق حساب 60 ثانية، ترتيب وتسلسل |
| 🔬 العلوم | اختبار تكيفي (فضاء، جسم، طبيعة، حالات المادة) |
| ✍️ اللغة العربية | اختبار، تهجئة كلمات، مولّد قصص |
| 🌍 المعلومات العامة | اختبار، مطابقة أزواج، ذاكرة |
| 🧠 تدريب المخ | ألغاز ومنطق، سلسلة الألوان، برق التفاعل، الذاكرة |
| 🎨 الإبداع | سبورة رسم، قصص، إيقاع موسيقي |
| 🏆 التحديات | امتحان شامل، امتحان رياضيات، تحدي يومي، تحدّي لاعبَين |

## السمات
- **عربي أولًا**: RTL كامل، قارئ عربي (TTS)، محتوى مدرسي صحيح.
- **تكيّف ذكي**: يراقب الدقة لكل مجال ولكل مستوى صعوبة ويعدل تحدي السؤال تلقائيًا
  (اختبار تقييم في أول تشغيل + محرك `engine.js`).
- **زنبرك الرجوع الصحيح**: في اللعبة → قائمة إيقاف مؤقت، في قسم → قائمة الأب،
  في الرئيسية → نافذة "هل تريد الخروج من اللعبة أو مواصلة اللعب؟".
- **تحفيز**: XP، عملات، صناديق كنز، ستيكرات، 20 إنجازًا، قيادات، سلسلة أيام.
- **ملف الطفل**: صورة رمزية ولون واسم + معرض رسوماته المحفوظ.
- **لوحة الوالدين**: محمي برمز سري، تقرير دقة لكل عالم وتوصيات المحرك الذكي.
- **مزايا الحفظ**: كل التقدم في `localStorage` (تُحفظ فورًا مع كل تغيير).

## بناء APK عبر GitHub Actions
 هذا المستودع جاهز للبناء في السحابة (لا يحتاج أندرويد ستوديو):

1. ارفع الملفات إلى مستودع على GitHub (الفرع `main`).
2. إجراء «Android APK» يُبنى تلقائيًا على كل دفع — أو شغّله يدويًا من
   تبويب **Actions → Android APK → Run workflow**.
3. نزّل `aqlni-debug-apk` أو `aqlni-release-apk` من صفحة الإجراء.

### التوقيع (اختياري)
لإنتاج APK موقّع جاهز للنشر:
```bash
keytool -genkeypair -v -keystore release.keystore -alias aqlni \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w 0 release.keystore > ks.b64
```
ثم أضف Secrets في المستودع:
- `AQ_KEYSTORE` = محتوى `ks.b64`
- `AQ_KEYSTORE_PASS` / `AQ_KEY_ALIAS` (`aqlni`) / `AQ_KEY_PASS`

بدون هذه الأسرار يُبنى APK إصداري غير موقّع (مفيد للاختبار الجانبي).

## تشغيل على حاسوب (اختياري للمطوّرين)
افتح `app/src/main/assets/index.html` في متصفح حديث — تعمل كل الشاشات والألعاب؛
فقط زر الهاتف الراجع والنطق الأصلي لن يكونا فعّالين خارج أندرويد.

## بنية المشروع
```
app/src/main/assets/          محرك اللعبة (HTML/CSS/JS) بلا إنترنت
  js/core/                    util, store, audio, ui, router, engine
  js/data/                    بنوك الأسئلة (رياضيات، علوم، عربية، معلومات، مخ) + محتوى الألعاب
  js/games/                   12 لعبة/محرك اختبار + أدوات مشتركة
  js/screens/                 الرئيسية، العالم، الامتحانات، ملفي، الإعدادات، الوالدين، التقييم
app/src/main/java/com/aqlni/game/   MainActivity.kt (صدفة أندرويد وجسر JS) + LevelPolicy.kt
app/src/test/                 اختبارات الوحدة لسياسة المستوى وعوالم الفتح
.github/workflows/android-build.yml  سلسلة البناء في CI
docs/                         معماري، اختبارات، دليل المحتوى
tools/                        فاحصات جودة بنوك الأسئلة (Node، تعمل محليًا)
```
