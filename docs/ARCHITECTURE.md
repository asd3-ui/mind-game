# المعمارية — عقلني

## نظرة عامة
اللعبة **موقع واحد بدون إنترنت** (single-page offline app):
HTML واحد + CSS واحد + ملفات JS بترتيب تحميل ثابت، يُدمج داخل WebView أندرويد
بواسطة `WebViewAssetLoader` ويُقدم من أصل ثابت `https://appassets.androidplatform.net`.
هذا الأصل يعطي `localStorage` موثوقًا، ويمنع الوصول لروابط خارجية (سياسة أمان للأطفال).

```
┌──────────────────────────── Android ────────────────────────────┐
│  MainActivity.kt                        LevelPolicy.kt          │
│  ├─ WebView (full screen, RTL)          منطق نقي مُختبَر         │
│  ├─ Bridge @JavascriptInterface "AqApp"  (unit tests in CI)     │
│  ├─ TTS عربي + صوت التركيز              └─ التقييم → مستوى      │
│  ├─ زر الراجع → __handleBack()                                   │
│  └─ دورة حياة (pause/resume TTS & WebView)                      │
└──────────────────────────────────────────────────────────────────┘
                  ▲                      │
                  │ window.__ttsState    ▼ AqApp.ttsSpeak/…
┌──────────────────────────────────────────────────────────────────┐
│ HTML5 game (assets/)                                             │
│  core: util → store → audio(+voice) → ui → router → engine       │
│  data: بنوك أسئلة (math/science/arabic/general/brain) + content  │
│  games: quiz (كويز تكيّفي) + 10 ألعاب + أدوات مشتركة utilg        │
│  screens: home/world/exams/profile/settings/parent/assessment    │
│  main.js: يربط ويرفع اللعبة                                     │
└──────────────────────────────────────────────────────────────────┘
```

## المكونات الأساسية
| الملف | الدور |
|---|---|
| `router.js` | مكدس الشاشات، الزنبرك المُنعكس (`__handleBack`)، نافذة الخروج العربية |
| `store.js` | حفظ الحالة في localStorage + XP/عملات/إنجازات/قيادات/ستيكرات/يوميات |
| `engine.js` | اختيار السؤال التكيّفي، مولّدات حساب وسلاسل، بناء امتحان، توصيات، سياسة عوالم |
| `audio.js` | مؤثرات WebAudio + موسيقى خلفية + `AQ.voice` (TTS أندرويد ثم Web) |
| `ui.js` | HUD، نوافذ، توست، احتفالات، صناديق كنز |
| `utilg.js` | أدوات مشتركة للألعاب: إطار إيقاف مؤقت، مكافآت، شاشة نتيجة موحدة |

## دورة زنبرك الراجع (كما طلبه المستخدم)
```
زر الهاتف الراجع
   ├─ نافذة مفتوحة؟ أغلقها.
   ├─ اللعبة الحالية {onBack}؟ اعرض استراحة (متابعة/إعادة/رجوع).
   ├─ أكثر من شاشة؟ ارجع لقائمة الأب.
   └─ الرئيسية؟ نافذة "هل تريد الخروج من اللعبة أو مواصلة اللعب؟"
```

## التكيّف (learning loop)
- `stats.byCat[cat].byDiff[d] = {asked, correct}` (الأسئلة 1..5 صعوبة).
- `targetDiff(cat)`: المستوى الأساسي من التقييم، مع +1 بعد نسبة نجاح 0.85 وسلسلة 3،
  و−1 تحت 0.45.
- «ذاكرة الاستفهام»: السؤال الذي انطوى آخر 3 أيام لا يعود إلا إن ضاق المكب.
- مولّدات الحساب/السلاسل (infinite) تضمن أسئلة جديدة دائمًا.

## الأمان (لطفل)
- لا إنترنت، لا تتبع، لا إعلانات.
- XML آمن للنطاق: كل روابط خارج appassets ممنوعة (MainActivity).
- كود ES2017 توافقًا مع WebViews الأقدم (بلا `?.` أو `??` أو NodeList.forEach).
